  · 공인 IP: 49.247.136.41   (알리고 발송 서버 IP 에 이 번호 등록)
  · 접속 계정: root / 비밀번호는 iwinv 에서 온 메일 참고

1단계. iwinv 가입 · 서버 만들기 (완료)
─────────────────────────────────────────────
  1) https://www.iwinv.kr 회원가입 → 카드 등록
  2) https://console.iwinv.kr → [컴퓨트 → 가상 서버] → [생성하기]
     · ZONE: KR1-Lite → KR1-Lite-Z01   (1GB 서버는 Lite 에만 있음)
     · 하드웨어: vgna_1_n (1 vCPU · 1 GB · 월 5,600원)
     · 운영체제: Ubuntu 24.04 LTS (26.04 는 너무 새 버전이라 피함)
     · 블록 스토리지: 추가하지 않음
     · 이름: dhcaravan / 네트워크: Direct IP 방식 / NAT · SSH Key · Script: 선택 안 함
  3) 메일로 온 IP · root 비밀번호 보관
  ※ 서버를 지우지 않는 한 IP 는 바뀌지 않습니다. 서버를 여러 개 만들면 그만큼 요금이 나갑니다.

─────────────────────────────────────────────
3단계. GitHub 토큰 만들기 (자동 반영용, 약 5분)
─────────────────────────────────────────────
  서버가 관리자 화면에서 바꾼 사진 · 요금을 GitHub 에 올릴 수 있게 하는 열쇠입니다.

  1) https://github.com 에 syyoon2-dhc 로 로그인
  2) 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
     → Personal access tokens → Fine-grained tokens → [Generate new token]
  3) Token name: dhc-cloud-server
     Expiration: 가장 길게 (만료되면 새로 만들어서 다시 넣어야 함)
     Repository access: "Only select repositories" → dhcaravan
     Permissions → Repository permissions → Contents: "Read and write"
  4) [Generate token] → github_pat_... 로 시작하는 토큰 복사 (이 화면에서만 보임 → 메모장에 잠깐 보관)

─────────────────────────────────────────────
4단계. 서버에 접속해서 설치 (약 15분, 집에서)
─────────────────────────────────────────────
  1) 시작 메뉴 → "PowerShell" 실행 → 아래 입력
        ssh root@49.247.136.41
     → "Are you sure you want to continue connecting" 물으면  yes  입력
     → 비밀번호: iwinv 메일의 root 비밀번호 (입력해도 화면에 안 보이는 게 정상) → 엔터
     → 화면 맨 아래가 root@...:~# 로 바뀌면 접속 성공

  2) 접속된 화면에서 아래 세 줄을 차례로 붙여넣기 (마우스 오른쪽 클릭 = 붙여넣기)
        apt-get update && apt-get install -y git
        git clone https://github.com/syyoon2-dhc/dhcaravan.git
        bash dhcaravan/cloud/setup.sh
     ※ 보안을 위해 서버 프로그램은 root 가 아닌 "dhc" 계정으로 실행됩니다.
       설치하면 프로그램이 /home/dhc/dhcaravan 폴더로 복사되어 거기서 돌아갑니다.

  3) 설치 중에 물어보는 것
     · 관리자 아이디 → 그냥 엔터 (admin)
     · 새 관리자 비밀번호 → 10자 이상, 어렵게 (글자가 안 보이는 게 정상)
       ★ 인터넷에 공개되는 관리자 화면이라 기존 비밀번호(dh1415!)는 쓰지 마세요.
     · GitHub 토큰 → 3단계에서 복사한 github_pat_... 붙여넣기 → 엔터
     · Tailscale 로그인 주소 (https://login.tailscale.com/...) 가 나오면
       → 그 주소를 PC 브라우저에 붙여넣어 지금 쓰는 Tailscale 계정으로 로그인
     · Funnel 허용 주소가 나오면 → 브라우저에서 열어 [Enable] 누르기

  4) 마지막에 이렇게 나오면 완료
        https://dhc.xxxx.ts.net (Funnel on)
        이 서버의 공인 IP (알리고에 등록): 49.247.136.41
     → 이 두 가지를 메모하세요.

─────────────────────────────────────────────
5단계. 홈페이지와 연결
─────────────────────────────────────────────
  1) PC 의 site\js\booking-config.js 를 메모장으로 열어 주소 입력
        window.DHC_API_BASE = 'https://dhc.xxxx.ts.net';
     → 저장 → "배포갱신.bat" 실행
     (또는 Claude 에게 주소만 알려주면 넣어 드립니다)
     → 2분쯤 뒤 클라우드 서버에도 자동으로 반영됩니다.

  2) 휴대폰 · PC 에서 관리자 화면 접속
        https://dhc.xxxx.ts.net/booking-admin.html     (예약 관리)
        https://dhc.xxxx.ts.net/admin.html             (사진 · 요금 관리)
     → 4단계에서 정한 아이디/비밀번호로 로그인

  3) 설정 다시 입력 (새 서버라 비어 있음)
     → [운영관리 → 환경설정] 입금 계좌 (기업은행)
     → [캠핑장관리 → 예약정보설정] 바베큐 수량 3, 환불기준 확인
     → [운영관리 → 문자발송설정] 알리고 API Key / 아이디 / 발신번호
     → [운영관리 → 문자발송설정 → 사장님 알림 — 텔레그램]  (아래 "텔레그램 연결" 참고)

  4) 알리고 발송 IP 등록 (알리고 사업자 · 발신번호 승인이 난 뒤)
     → 알리고 사이트 [문자 API → 신청/인증] 의 발송 서버 IP 에 49.247.136.41 등록
     → 서버 IP 는 바뀌지 않으므로 한 번만 하면 됩니다.
     → 승인 전까지는 [문자 발송 사용] 을 꺼 두세요. 예약 · 텔레그램 알림은 그대로 됩니다.

  ★ 텔레그램 연결 (사장님 알림, 무료) — 휴대폰 텔레그램 앱으로
     ① 텔레그램에서 @BotFather 검색 → [시작] → /newbot 입력
        → 봇 이름 (예: 동해카라반알림) → 봇 아이디 (영어, _bot 으로 끝나게. 예: dhcaravan_alarm_bot)
        → 123456789:AA... 처럼 생긴 "토큰" 이 나옴 → 복사
     ② 관리자 화면 [운영관리 → 문자발송설정] → "사장님 알림 — 텔레그램" 칸에
        봇 토큰 붙여넣기 → "문자 대신 텔레그램으로 받기" 체크 → [설정 저장]
     ③ 텔레그램에서 방금 만든 봇을 검색해 [시작] → 아무 말이나 보내기 (예: 안녕)
     ④ 관리자 화면 [채팅 ID 찾기] → [설정 저장] → [테스트 메시지 보내기]
        → 텔레그램에 "✅ 예약 알림이 연결되었습니다" 가 오면 완료
     ※ 회사 PC 에서는 텔레그램이 막혀 있지만, 서버가 보내는 것이라 관리자 화면 설정은 어디서 해도 됩니다.
       (휴대폰 텔레그램 앱으로 받으면 됨)

  5) 확인: 휴대폰으로 GitHub 홈페이지 → [실시간 예약] → 테스트 예약 1건
     → 관리자 화면에 들어오는지, 텔레그램 알림이 오는지 확인 → 테스트 예약 취소 후 삭제

  6) 펜션 PC · 노트북의 "서버실행.bat" 은 이제 끄고, 시작프로그램에서도 빼세요.
     (두 서버를 같이 켜 두면 예약이 두 곳으로 나뉩니다)

  서버 상태 확인 · 문제 해결 (4단계 1)처럼 접속한 뒤 입력)

     tail -20 /home/dhc/dhcaravan/private/sync.log    GitHub 자동 반영 기록

  · GitHub 토큰이 만료되면 (sync.log 에 "올리기 실패")
