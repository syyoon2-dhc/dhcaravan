■ 동해카라반펜션 예약 서버 — 오라클 클라우드 무료 서버로 옮기기

  펜션 PC · 노트북을 켜 둘 필요 없이, 오라클 회사의 무료 서버(춘천/서울)에서
  예약 서버가 24시간 돌아갑니다. 비용 0원.

  이렇게 바뀝니다
  · 홈페이지(사진 · 소개)는 지금처럼 GitHub 에 그대로 있음
  · 예약 서버(손님 예약 · 관리자 화면 · 문자)만 오라클 서버에서 실행
  · 관리자 화면에서 사진 · 요금 · 팝업을 고치면 2분 안에 GitHub 홈페이지에 자동 반영
    (배포갱신.bat 을 따로 누를 필요 없음)

  ※ 집에서 하세요. 회사 인터넷은 GitHub · 서버 접속(SSH)이 막혀 있습니다.
  ※ 전체 1~2시간 정도 걸립니다.

─────────────────────────────────────────────
0단계. 준비 — 지금까지 만든 내용 GitHub 에 올리기
─────────────────────────────────────────────
  site 폴더의 "배포갱신.bat" 실행
  → 예약 시스템 · 개인정보 처리방침 · 설치 스크립트(cloud 폴더)가 GitHub 에 올라감
  ※ 이걸 먼저 해야 오라클 서버가 프로그램을 받아갈 수 있습니다.

─────────────────────────────────────────────
1단계. 오라클 클라우드 가입 (약 20분)
─────────────────────────────────────────────
  1) https://www.oracle.com/kr/cloud/free/ → [무료로 시작하기]
  2) 국가: 대한민국 / 이름 · 이메일 입력 → 이메일 인증
  3) ★ 홈 지역(Home Region): "South Korea North (Chuncheon)" 또는
     "South Korea Central (Seoul)" 선택
     → 나중에 바꿀 수 없고, 무료 서버는 홈 지역에서만 만들 수 있습니다.
  4) 주소 · 휴대폰 인증 → 신용카드 등록
     → 본인 확인용 임시 결제(약 1달러)가 됐다가 취소됩니다. 요금은 나가지 않습니다.
  5) 가입 완료 메일이 오면 https://cloud.oracle.com 로그인
     (계정 생성에 몇 분~몇 시간 걸릴 수 있음)

  ★ 꼭 하기: 종량제(Pay As You Go)로 업그레이드
     무료 계정 그대로 두면 "거의 안 쓰는 서버"로 보고 오라클이 서버를 회수할 수 있습니다.
     예약 서버는 하는 일이 적어 회수 대상이 될 수 있습니다.
     → 오른쪽 위 프로필 → 청구 및 지불 → [업그레이드 및 지불 관리] → Pay As You Go 로 업그레이드
     → 무료 범위(Always Free) 안에서 쓰면 계속 0원입니다.
     → 혹시 모르니 [청구 및 지불 → 예산] 에서 예산 1,000원 · 알림 메일을 설정해 두세요.

─────────────────────────────────────────────
2단계. 서버 만들기 (약 10분)
─────────────────────────────────────────────
  1) 왼쪽 위 메뉴(≡) → 컴퓨트 → 인스턴스 → [인스턴스 생성]
  2) 이름: dhc
  3) 이미지와 구성
     · 이미지 [이미지 변경] → Ubuntu → "Canonical Ubuntu 24.04" (또는 22.04)
     · 구성(Shape) [구성 변경] → 둘 중 하나 ("Always Free 적격" 표시 확인)
         Ampere → VM.Standard.A1.Flex  · OCPU 1개 · 메모리 6GB   (추천, 넉넉함)
         AMD    → VM.Standard.E2.1.Micro                       (A1 이 "용량 부족"으로 안 될 때)
  4) 네트워킹: "새 가상 클라우드 네트워크 생성" · "공용 IPv4 주소 지정" 체크 (기본값 그대로)
  5) SSH 키 추가: "키 쌍 생성" → [개인 키 저장] 눌러 파일(ssh-key-....key) 내려받기
     ★ 이 파일이 서버 열쇠입니다. 잃어버리지 말고 다른 사람에게 주지 마세요.
  6) [생성] → 1~2분 뒤 상태가 "실행 중" 이 되면
     화면의 "공용 IP 주소" (예: 152.70.xx.xx) 를 메모

─────────────────────────────────────────────
3단계. GitHub 토큰 만들기 (자동 반영용, 약 5분)
─────────────────────────────────────────────
  서버가 관리자 화면에서 바꾼 사진 · 요금을 GitHub 에 올릴 수 있게 하는 열쇠입니다.

  1) https://github.com 에 syyoon2-dhc 로 로그인
  2) 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
     → Personal access tokens → Fine-grained tokens → [Generate new token]
  3) Token name: dhc-cloud-server
     Expiration: 가장 길게 (만료되면 새로 만들어서 다시 넣어야 함)
     Repository access: "Only select repositories" → dhcaravan
     Permissions → Repository permissions → Contents: "Read and write"
  4) [Generate token] → github_pat_... 로 시작하는 토큰 복사 (이 화면에서만 보임 → 메모장에 잠깐 보관)

─────────────────────────────────────────────
4단계. 서버에 접속해서 설치 (약 15분)
─────────────────────────────────────────────
  1) 내려받은 키 파일을 C:\Users\(내 이름)\.ssh\ 폴더로 옮기고 이름을 oracle.key 로 바꾸기
     (.ssh 폴더가 없으면 만드세요)

  2) 시작 메뉴 → "PowerShell" 실행 → 아래 입력 (공용 IP 는 2단계에서 메모한 번호)
        ssh -i $HOME\.ssh\oracle.key ubuntu@공용IP
     → "Are you sure you want to continue connecting" 물으면  yes  입력
     → 화면 맨 아래가 ubuntu@dhc:~$ 로 바뀌면 접속 성공

     ※ "UNPROTECTED PRIVATE KEY FILE" 오류가 나면 아래 한 줄 실행 후 다시 접속
        icacls $HOME\.ssh\oracle.key /inheritance:r /grant:r "$($env:USERNAME):R"

  3) 접속된 화면에서 아래 두 줄을 차례로 붙여넣기 (마우스 오른쪽 클릭 = 붙여넣기)
        git clone https://github.com/syyoon2-dhc/dhcaravan.git
        bash dhcaravan/cloud/setup.sh

  4) 설치 중에 물어보는 것
     · 관리자 아이디 → 그냥 엔터 (admin)
     · 새 관리자 비밀번호 → 10자 이상, 어렵게 (글자가 안 보이는 게 정상)
       ★ 인터넷에 공개되는 관리자 화면이라 기존 비밀번호(dh1415!)는 쓰지 마세요.
     · GitHub 토큰 → 3단계에서 복사한 github_pat_... 붙여넣기 → 엔터
     · Tailscale 로그인 주소 (https://login.tailscale.com/...) 가 나오면
       → 그 주소를 PC 브라우저에 붙여넣어 지금 쓰는 Tailscale 계정으로 로그인
     · Funnel 허용 주소가 나오면 → 브라우저에서 열어 [Enable] 누르기

  5) 마지막에 이렇게 나오면 완료
        https://dhc.xxxx.ts.net (Funnel on)
        이 서버의 공인 IP (알리고에 등록): 152.70.xx.xx
     → 이 두 가지를 메모하세요.

─────────────────────────────────────────────
5단계. 홈페이지와 연결
─────────────────────────────────────────────
  1) PC 의 site\js\booking-config.js 를 메모장으로 열어 주소 입력
        window.DHC_API_BASE = 'https://dhc.xxxx.ts.net';
     → 저장 → "배포갱신.bat" 실행
     (또는 Claude 에게 주소만 알려주면 넣어 드립니다)
     → 2분쯤 뒤 클라우드 서버에도 자동으로 반영됩니다.

  2) 휴대폰 · PC 에서 관리자 화면 접속
        https://dhc.xxxx.ts.net/booking-admin.html     (예약 관리)
        https://dhc.xxxx.ts.net/admin.html             (사진 · 요금 관리)
     → 4단계에서 정한 아이디/비밀번호로 로그인

  3) 설정 다시 입력 (새 서버라 비어 있음)
     → [운영관리 → 환경설정] 입금 계좌 (기업은행)
     → [캠핑장관리 → 예약정보설정] 바베큐 수량 3, 환불기준 확인
     → [운영관리 → 문자발송설정] 알리고 API Key / 아이디 / 발신번호
     → 텔레그램 봇 토큰 · 채팅 ID (예약관리_설치방법.txt 4단계)

  4) 알리고 발송 IP 등록
     → 알리고 사이트 [문자 API → 발송 서버 IP] 에 4단계 5)의 "공인 IP" 등록
     → 클라우드 서버 IP 는 바뀌지 않으므로 한 번만 하면 됩니다.

  5) 확인: 휴대폰으로 GitHub 홈페이지 → [실시간 예약] → 테스트 예약 1건
     → 관리자 화면에 들어오는지, 문자 · 텔레그램 알림이 오는지 확인 → 테스트 예약 삭제

  6) 펜션 PC · 노트북의 "서버실행.bat" 은 이제 끄고, 시작프로그램에서도 빼세요.
     (두 서버를 같이 켜 두면 예약이 두 곳으로 나뉩니다)

앞으로 운영
─────────────────────────────────────────────
  · 사진 · 요금 · 팝업 수정은 클라우드 관리자 화면(https://dhc.xxxx.ts.net/admin.html)에서만 하세요.
    2분 안에 GitHub 홈페이지에 자동 반영됩니다.
    ※ PC 에서 직접 파일을 고치고 배포갱신.bat 을 쓰면, 같은 파일을 양쪽에서 고칠 때 충돌할 수 있습니다.
       PC 에서 고칠 때는 먼저 "배포갱신.bat" 으로 최신 내용을 받은 뒤 고치세요.
  · 서버는 꺼져도 자동으로 다시 켜지고, 오라클 서버가 재부팅돼도 자동 실행됩니다.
  · 예약 데이터: 서버의 ~/dhcaravan/private/booking.db (매일 자동 백업, 60일 보관)
    → 가끔 관리자 화면 [예약목록 → 엑셀] 로 내려받아 PC 에 보관해 두세요.

  서버 상태 확인 · 문제 해결 (4단계 2)처럼 접속한 뒤 입력)
     sudo systemctl status dhc            서버 상태 (active (running) 이면 정상)
     sudo systemctl restart dhc           서버 다시 시작
     sudo journalctl -u dhc -n 50         서버 오류 기록
     tail -20 ~/dhcaravan/private/sync.log    GitHub 자동 반영 기록
     tailscale funnel status              인터넷 주소 확인
     exit                                 접속 종료

  · 관리자 비밀번호 바꾸기
     nano ~/dhcaravan/admin_config.json   → 고친 뒤 Ctrl+O, 엔터, Ctrl+X
     sudo systemctl restart dhc

  · GitHub 토큰이 만료되면 (sync.log 에 "올리기 실패")
     3단계대로 새 토큰을 만든 뒤:
     rm ~/.git-credentials && bash ~/dhcaravan/cloud/setup.sh   (토큰 질문에 새 토큰 입력)
