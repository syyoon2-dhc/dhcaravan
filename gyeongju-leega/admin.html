관리자 로그인

홈페이지 파일이 있는 GitHub 저장소에 바로 저장합니다. GitHub 토큰을 넣어 주세요.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: 이 홈페이지 저장소만 선택
  3. Permissions → Contents: Read and write
  4. 만든 토큰을 위 칸에 붙여 넣기 (토큰은 이 기기에만 저장되고 다른 곳으로 보내지 않습니다)
