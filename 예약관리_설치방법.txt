■ 동해카라반펜션 자체 예약 시스템 — 설치 · 사용 방법

  ※ 서버는 오라클 클라우드 무료 서버로 운영합니다 → "클라우드서버_설치방법.txt" 참고
     (아래 1 · 2단계의 펜션 PC · Cloudflare 방식 대신)

  손님 예약 화면 :  reserve.html        (홈페이지의 "실시간 예약" 버튼)
  관리자 화면    :  booking-admin.html  (홈페이지 맨 아래 "예약 관리" 링크)
  로그인         :  사진 관리와 같은 아이디/비밀번호 (admin_config.json)

─────────────────────────────────────────────
1단계. 펜션 PC 에서 서버 켜기  (오늘 바로 가능)
─────────────────────────────────────────────
  1) site 폴더의 "서버실행.bat" 을 더블클릭
     → 검은 창이 뜨면 정상. 닫지 말고 최소화.
     (멈추면 5초 뒤 자동으로 다시 켜집니다)

  2) PC 를 켤 때 자동 실행되게 하기
     - 키보드 [윈도우키 + R] → shell:startup 입력 → 확인
     - 열린 폴더에 "서버실행.bat" 의 바로가기를 넣기
       (파일을 마우스 오른쪽 버튼으로 끌어다 놓고 "바로 가기 만들기")

  3) PC 절전 끄기 (꺼지면 예약을 못 받음)
     - 설정 → 시스템 → 전원 → "절전 모드" 를 "안 함" 으로

  4) 브라우저에서 http://localhost:8000/booking-admin.html 접속 → 로그인
     → [운영관리 → 환경설정] 입금 계좌 확인 (기업은행 계좌가 미리 들어가 있음)
        ※ 계좌가 비어 있으면 손님 예약이 열리지 않습니다
     → [캠핑장관리 → 예약정보설정] 2박 우선 · 환불기준 · 성수기 · 공휴일 · 바베큐 수량 확인
     → [캠핑장관리 → 임시요금관리] 할인 기간이 있으면 등록

  5) 땡큐캠핑에 이미 들어와 있는 예약 옮기기
     → [예약관리 → 예약현황] 에서 객실 클릭 → 종류 "예약확정", 경로 "땡큐캠핑" 으로 등록
     → 땡큐캠핑 캠퍼목록을 엑셀로 받아 [고객관리 → 엑셀/CSV 가져오기] 로 올리면 고객 명단도 옮겨집니다
     → 다 옮긴 뒤 땡큐캠핑 판매를 중지하세요 (두 곳에서 받으면 중복 예약 위험)

─────────────────────────────────────────────
2단계. 인터넷에서 접속되게 하기 (Cloudflare Tunnel · 무료)
─────────────────────────────────────────────
  손님이 집에서 예약하려면 펜션 PC 서버가 인터넷 주소를 가져야 합니다.
  공유기 설정은 필요 없습니다.

  준비물: 도메인 1개 (예: dhcaravan.com — 가비아/Cloudflare 에서 연 1~2만원)

  1) https://dash.cloudflare.com 가입 → 도메인을 Cloudflare 에 추가 (무료 플랜)
     (가비아에서 샀다면 네임서버를 Cloudflare 가 알려주는 값으로 변경)

  2) Cloudflare 화면 → Zero Trust → Networks → Tunnels → "Create a tunnel"
     → Cloudflared 선택 → 이름: dhc → Windows 선택
     → 화면에 나오는 명령어 (cloudflared.exe service install eyJ...) 를
        펜션 PC 의 "관리자 권한 PowerShell" 에 붙여넣기
        (cloudflared 가 없으면 먼저: winget install --id Cloudflare.cloudflared)

  3) Public Hostname 추가
        Subdomain : booking        Domain : dhcaravan.com (내 도메인)
        Type      : HTTP           URL    : localhost:8000
     → 저장하면 https://booking.dhcaravan.com 으로 접속됩니다 (자동 HTTPS)

  4) site\js\booking-config.js 파일을 메모장으로 열어 주소 입력
        window.DHC_API_BASE = 'https://booking.dhcaravan.com';
     → "배포갱신.bat" 실행 (GitHub 홈페이지에 반영)
     → 이제 GitHub 홈페이지의 [실시간 예약] 에서도 예약이 됩니다.
       (주소를 넣기 전에는 "전화로 예약" 안내가 나옵니다)

  5) 밖에서 관리하기
     → 휴대폰으로 https://booking.dhcaravan.com/booking-admin.html

  ※ 인터넷에 열리므로 관리자 비밀번호를 길고 어렵게 바꾸세요
     (admin_config.json 수정 후 서버 재시작). 로그인 10번 틀리면 10분 잠김.

─────────────────────────────────────────────
3단계. 예약 문자 (알리고)
─────────────────────────────────────────────
  1) https://smartsms.aligo.in 가입 → 충전 → 발신번호 등록 (010-4589-1415, 서류 인증)
  2) [문자 API] → [신청/인증] → API Key 발급
  3) 발송 서버 IP 등록:
     [운영관리 → 문자발송설정] → [이 PC 인터넷 IP 확인] 에 나온 번호를 알리고에 등록
     ※ 회사·집 IP 가 아니라 "펜션 PC" 의 IP 여야 합니다
     ※ 펜션 인터넷 IP 가 바뀌면 문자가 실패합니다 → [문자] 탭 기록에 "실패" 로 표시
        → 새 IP 를 다시 등록하세요
  4) [운영관리 → 문자발송설정] 에 API Key / 알리고 아이디 / 발신번호 입력
     → "테스트 모드" 체크 + "문자 발송 사용" 체크 → 저장 → [잔여 건수 확인]
     → 문제 없으면 테스트 모드 끄고 저장

  ※ 손님 문자는 모두 단문(8.4원) 길이로 맞춰져 있습니다 (예약 1건당 약 25원)

  자동으로 나가는 문자 (문구는 [운영관리 → 문자발송설정] 에서 수정 가능):
     · 예약 접수 (입금 계좌 안내)   · 입금 확인 → 예약 확정
     · 예약 취소                    · 입금기한 초과 자동 취소
     · 입실 전날 안내 (설정한 시각)  · 새 예약 알림 (사장님 휴대폰으로)

─────────────────────────────────────────────
4단계. 사장님 알림 — 텔레그램 (무료)
─────────────────────────────────────────────
  ※ 회사 네트워크에서는 텔레그램이 막혀 있을 수 있음 → 펜션 PC / 집에서 설정
  1) 휴대폰 텔레그램에서 @BotFather 검색 → /newbot → 봇 이름 → 아이디(_bot 으로 끝남)
     → 받은 토큰을 [운영관리 → 문자발송설정 → 텔레그램] 에 붙여넣고 [설정 저장]
     (토큰은 비밀번호와 같으니 다른 곳에 알려주지 마세요)
  2) 만든 봇을 찾아 [시작] → 아무 말이나 보내기 → [채팅 ID 찾기] → [설정 저장]
  3) [테스트 메시지 보내기] → 휴대폰에 도착하면 완료
     새 예약 · 손님 취소 · 미입금 자동취소가 텔레그램으로 옵니다 (문자비 0원)

─────────────────────────────────────────────
매일 하는 일
─────────────────────────────────────────────
  · 새 예약 알림 문자가 오면 → 통장 입금 확인
    → [예약현황] 노란색(입금대기) 예약 클릭 → [입금 확인 → 예약 확정]
  · 기한 안에 입금이 없으면 자동 취소되고 손님에게 문자가 나갑니다.
  · 전화 예약 · 현장 예약도 [예약현황] 빈 칸을 눌러 등록 (그래야 중복 예약이 막힘)
  · 수리 · 개인 사용으로 못 파는 날은 "예약막음" 으로 등록

─────────────────────────────────────────────
요금 규칙 (자동 계산)
─────────────────────────────────────────────
  · 객실 요금은 [사진·요금 관리] 의 요금표를 그대로 사용
  · 주말 요금 = 토요일 · 공휴일 전날 · 성수기 금요일 (비수기 금요일은 평일 요금)
  · 성수기 기간 · 공휴일은 예약관리 [설정] 에서 수정
  · 인원 추가 요금은 요금표 "비고" 의 금액(1인 1박)을 읽어서 계산
    (예: "인원 추가 1인 10,000원" → 기준 인원 초과 1명당 1박 10,000원)
  · 관리자가 등록할 때는 총 금액을 직접 고쳐 할인할 수 있음
